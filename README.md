## Setting up locally
### Manually using your shell
  Clone the repo:

    git clone https://github.com/delindblad/frontend_project.git

  Enter the cloned directory:

    cd frontend_project

  You need to have node.js installed:
    https://nodejs.org/en/download

  Install dependecies:

    npm install

  Start the dev server:
    
      npm run dev
